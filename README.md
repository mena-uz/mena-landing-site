# Mena: сайт trymena.app

Статичный лендинг: один `index.html` и папка `media/`. Сборка, Node и зависимости не нужны.

## Структура

```
index.html      страница: разметка, стили и скрипт в одном файле
media/          ролики экранов (mp4 + webm), обложки к ним, картинка экрана блокировки
favicon.svg     иконка вкладки
og.jpg          превью ссылки в мессенджерах и соцсетях (1200×630)
robots.txt, sitemap.xml
vercel.json     кэш для media/ и базовые заголовки безопасности
```

## Посмотреть локально

```
npx serve .
```
или `python3 -m http.server 8000` и открыть http://localhost:8000.
Открыть index.html двойным кликом тоже можно, но видео в некоторых браузерах так не играют.

## Захостить на Vercel (рекомендую)

1. Загрузить этот репозиторий на GitHub.
2. vercel.com → Add New → Project → выбрать репозиторий. Framework Preset: Other, Build Command пустой, Output Directory: `.`
3. Deploy. Через минуту сайт на адресе вида mena-site.vercel.app.
4. Settings → Domains → добавить `trymena.app` и `www.trymena.app`, прописать у регистратора DNS-записи, которые покажет Vercel. HTTPS включится сам.

Каждый пуш в main обновляет сайт автоматически.

Без GitHub: `npx vercel` в этой папке.
Подойдут и Netlify, и Cloudflare Pages: папка публикации `.`, сборки нет. `vercel.json` там просто игнорируется.

## Что заполнить перед запуском

Всё в `index.html`, искать поиском:

- **PostHog.** В начале первого `<script>` строка `var KEY='';`. Вставить Project API key из PostHog (EU cloud). Пока ключ пустой, аналитика не грузится.
  Само собой собираются посещения и клики. Отдельные события: `download_click` (store, place), `social_click`, `faq_open`, `score_toggle`.
- **Кнопки сторов.** Сейчас `href="#get"` у всех `class="store"`. Когда появятся ссылки на App Store и Google Play, заменить.
- **Соцсети.** `https://instagram.com/trymena` и `https://t.me/trymena`: проверить, что это ваши аккаунты.
- **Terms.** В подвале ссылка `href="#"`, нужна страница с условиями. Privacy сейчас ведёт на блок про приватность, для сторов понадобится полноценная страница политики.

## Как устроены видео

- Ролики 540×1170, 60 к/с, H.264 (mp4) и VP9 (webm) как запасной вариант.
- Видео первого экрана грузятся сразу, остальные начинают загружаться примерно за экран до того, как до них долистают, и играют только пока их видно.
- При включённом в системе «уменьшении движения» видео не проигрываются, показываются обложки.

## Тема

Светлая или тёмная по настройке системы пользователя (`prefers-color-scheme`), переключателя нет.
